# Pawsh — Claude instructions

## Zero-reference policy (mandatory)

Claude may assist with development in this repository, but must never identify or reference itself, its provider, its model, or its involvement in any repository artifact it creates or modifies.

The policy document itself is the sole exception where naming the prohibited tools/providers is necessary to define this rule.

### Never introduce

- `Claude`
- `Claude Code`
- `Anthropic`
- Claude model names
- `noreply@anthropic.com`
- `Co-Authored-By` attribution identifying Claude
- `Generated with Claude`
- `Generated by Claude`
- AI/tool attribution identifying Claude or Anthropic
- Equivalent authorship, attribution, provenance, signature, footer, badge, or metadata

### Applies to all repository artifacts

This includes commit messages, authorship and co-authorship metadata, pull request titles and descriptions, issues and comments, release notes, changelogs, documentation, README files, source-code comments, generated files, build artifacts, Git notes, Git tags and tag messages, patches, diffs, provenance information, badges, footers, signatures, and hidden or machine-readable metadata under Claude's control.

### Git requirements

- Use only the repository's existing configured human Git identity.
- Never substitute or configure Claude, Claude Code, Anthropic, an Anthropic email address, model identity, or bot identity.
- Never override `user.name` or `user.email` to identify Claude or Anthropic.
- Commit messages must contain only the requested repository-relevant content.
- Never append AI/tool attribution or provenance trailers.
- Pull requests must contain no Claude/Anthropic attribution or generated-by notices.

### Existing functional content

Do not proactively delete or alter existing user-authored content, application functionality, dependencies, SDKs, APIs, tests, or integrations merely because they legitimately contain a prohibited name.

The restriction is against Claude introducing references to itself, its provider, model identity, or development involvement.

### Configuration enforcement

`.claude/settings.json` must maintain:

{
  "attribution": {
    "commit": "",
    "pr": ""
  }
}

Do not enable any legacy or future setting that automatically adds Claude/Anthropic attribution.

### Permanent behavior

For all future work in this repository, produce repository artifacts as ordinary project artifacts without identifying Claude, Anthropic, the model used, or AI/tool involvement.

Do not modify Git history, attribution configuration, or this policy unless explicitly instructed by the user.
